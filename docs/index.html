About SokoData

SokoData is the Open Data Commons for Zimbabwe — 22 datasets, one API, one catalog. It started with food-market prices and now covers every angle: economy (ZiG/USD, CPI, fuel), climate (rainfall/temperature), demographics (2022 Census), agriculture (yields, FAO), health, education, energy, water, transport, mining, governance, trade, labour, environment, poverty, ICT, finance, tourism, aid, gender and geospatial boundaries.

Sources are open where possible (WFP via HDX CC BY-IGO, World Bank WDI CC BY-4.0, Open-Meteo CC BY-4.0, FAO) and scraped where no API exists (RBZ, ZIMSTAT, ZERA, ZINWA, MoT, Chamber of Mines, ZEC, MoPSE, EMA, POTRAZ, HDX COD-AB). Every dataset is documented, attributed via /v1/catalog/{id} and /health, and built by the same fetch → clean → store → API pattern in src/sokodata/datasets/<name>/ registered in src/sokodata/core/registry.py.

Where there's no open API, the commons scrapes HTML tables and PDFs (src/sokodata/core/fetch.py: fetch_html_tables, extract_pdf_tables) with graceful fallback — if a ministry page changes, the ETL logs a warning and serves the World Bank fallback instead of failing.

Source code on GitHub — pull requests welcome. Built by Alfred Shingai. Not affiliated with WFP or HDX.

How to use

  • GET /v1/catalog — list all 22 datasets, sources, licenses, freshness
  • GET /v1/prices?market_id=&commodity_id=&start=&end= — raw price series (markets)
  • GET /v1/climate/daily?admin1=Harare — daily precip + temp (climate)
  • GET /v1/economy/cpi, /v1/demographics/annual, /v1/agriculture/annual etc.
  • Interactive docs at sokodata.onrender.com/docs
