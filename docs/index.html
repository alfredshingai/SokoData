About SokoData

SokoData answers a simple question — what does food cost at my market, and is that normal? — for Zimbabwe's food markets, using open data from the World Food Programme Price Database (via HDX, licensed CC BY-IGO).

The pipeline refreshes from the live WFP feed on every boot, cleans and currency-normalizes the data (Zimbabwe's 2024 currency reform broke naive comparisons — see how we handle that in the data dictionary), and serves it through an open-source API that anyone can build on.

Source code on GitHub — pull requests welcome. Built by Alfred Shingai. Not affiliated with WFP or HDX.
